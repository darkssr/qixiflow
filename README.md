# 七夕 · 鹊桥仙

一个纯前端的七夕主题动画：银河横亘，喜鹊自两岸飞来搭成鹊桥，牛郎与织女踏桥相会，秦观的《鹊桥仙》随之竖排显现。

无框架、无构建步骤，原生 Canvas 2D + 一点 CSS/DOM。

## 运行

```bash
python3 -m http.server 4173
```

然后打开 http://localhost:4173/ 。

> 直接双击 `index.html` 也能跑（脚本全部是传统 `<script>`，没有 ES module），
> 但背景音乐依赖 `fetch` 探测文件，走 `file://` 会被浏览器拦下，只会回退到内置合成音。
> 想听到 `bgm/` 里的音乐，请用上面的方式起一个本地服务。

## 这里面有什么

**画面时间轴**（约 18 秒，之后进入常态）

| 时间 | 内容 |
|---|---|
| 0–3s | 星空显影，银河渐亮 |
| 0.7–5.6s | 标题「七夕 · 鹊桥仙」浮现后散去 |
| 2.6s | 织女与牛郎在银河两岸亮起 |
| 6.5–13s | 喜鹊自两岸飞入，由外向中心搭成鹊桥 |
| 13.6–16.4s | 两人沿桥相向而行 |
| 16.4s | 相会：白光、心形烟花、花瓣骤起 |
| 17s 起 | 《鹊桥仙》逐字竖排显现 + 朱砂落款印 |

**技术要点**

- **银河**：程序化生成。云气用值噪声 fbm 逐像素算在半分辨率 `ImageData` 上再放大，叠加解析式的带状密度与暗尘带；星点用拒绝采样让其向银河聚集。整体烘焙进离屏画布，逐帧只做一次 `drawImage`。
- **水面倒影**：把烘焙好的星空垂直翻转缓存一份，逐帧按 3px 条带做正弦位移绘制，配合深度衰减的透明度与波光。
- **喜鹊**：全矢量绘制，`sin` 驱动振翅；沿二次贝塞尔飞入各自的桥上席位，由两端向中心依次抵达。
- **牛郎织女**：矢量人物，局部坐标系以「脚在原点、头顶 y=-1」归一化。织女取古神话嫦娥的意象（双环望仙髻、步摇、广袖曳地长裙、三重飘带），牛郎为束发玉冠、宽肩劲装、大氅当风。
- **性能**：辉光一律用预烘焙的径向渐变精灵 `drawImage`，避开昂贵的 `shadowBlur`。

## 交互

| 操作 | 效果 |
|---|---|
| 点击夜空 | 心形烟花绽开 + 五声音阶拨弦 |
| 移动鼠标 | 星空视差 |
| 输入心愿 → 放灯 | 孔明灯载着文字升空 |
| 输入 `碰碰` → 放灯 | 随机位置抽出一枝光之玫瑰，并切到专属曲，放完自动切回 |
| `重播` / 按 `R` | 从头再放一遍 |
| `♫` | 背景音乐开关 |
| `♪` | 交互音效开关 |

调试用：控制台里 `QX.seek(16)` 跳到指定秒，`QX.pause()` / `QX.play()` 定格与继续，`QX.rose()` 直接开一朵玫瑰。

## 音乐

- `bgm/xingchendahai.mp3` —— 默认背景乐，循环播放
- `bgm/pp.mp3` —— 触发 `碰碰` 彩蛋时的插曲，播完自动切回默认曲

两者都缺失时，页面会回退到内置的合成古风环境音（D 宫五声音阶的疏落拨弦 + 低音持续音，WebAudio 实时合成）。

换成自己的曲子：把文件放进 `bgm/`，改 `js/scene.js` 里的 `Q.bgm.probe(...)` 路径即可。

> 浏览器的自动播放策略要求先有一次用户交互，所以音乐会在你第一次点击/按键时起。

## 移动端

手机竖屏打开会提示横屏观看（银河是横向构图），也可以选「仍要竖屏」继续。横屏下 UI 会整体收一档，DPR 上限降到 1.6，粒子数量相应减少。
